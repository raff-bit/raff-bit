## Featured projects

### [Recovery Interface](https://github.com/raff-bit/Recovery-interface)
A training-recovery tracker that shows, muscle by muscle, how ready your body is for the next session. Log a workout and an exponential-decay fatigue model updates a body map of 17 muscle groups; plan a session and see your projected readiness.

**PHP · MySQL · JavaScript** · no frameworks, four-layer architecture · CSRF, CSP and login throttling · CI with PHPStan, 76 unit and 92 end-to-end tests · Excel export written from scratch · AGPL-3.0
